# ✅ JavaScript Todo App

A task management app built with vanilla JavaScript, HTML, and CSS. Add, complete, and remove tasks with a clean, responsive interface.

🔗 **Live Demo:** [cristibalanean.github.io/javascript-todo-app](https://cristibalanean.github.io/javascript-todo-app/)

---

## Features

- Add and remove tasks
- Mark tasks as complete
- Clean, minimal UI with custom styling
- Responsive layout that works on mobile and desktop
- No frameworks or dependencies — pure vanilla JS

---

## Tech Stack

- **HTML** — Semantic page structure
- **CSS** — Custom styling and responsive layout
- **JavaScript** — DOM manipulation, event handling, dynamic list rendering

---

## Project Structure

```
├── index.html       # App markup
├── styles/          # CSS stylesheets
├── scripts/         # JavaScript logic
├── images/          # UI icons and assets
└── README.md
```

---

## Getting Started

```bash
git clone https://github.com/CristiBalanean/javascript-todo-app.git
cd javascript-todo-app
```

Open `index.html` in your browser — no build step needed.
